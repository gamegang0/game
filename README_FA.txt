پروژه اندروید بازی «فرار از زیرزمین شهر فرش»

این پروژه فایل zirzamin.html ارسالی شما را داخل برنامه قرار می‌دهد و با Android WebView در حالت افقی و تمام‌صفحه اجرا می‌کند.

ساخت APK با Android Studio:
1) Android Studio را نصب و اجرا کنید.
2) از File > Open پوشه ZirzaminAPK را انتخاب کنید.
3) اجازه دهید Gradle Sync تمام شود و Android SDK Platform 35 نصب باشد.
4) از منوی Build > Build Bundle(s) / APK(s) > Build APK(s) را انتخاب کنید.
5) پس از پایان، روی locate بزنید. فایل معمولاً در app/build/outputs/apk/debug/app-debug.apk است.
6) فایل APK را به گوشی منتقل و نصب کنید. ممکن است اندروید اجازه نصب از منبع فایل‌منیجر را بخواهد.

نکته‌های مهم:
- بخش تک‌نفره و محتوای داخل HTML در خود برنامه قرار دارد و برای اجرای آن اینترنت لازم نیست.
- کد چندنفره در HTML به Supabase Realtime و WebRTC وابسته است؛ بنابراین ساخت/ورود اتاق و بازی آنلاین اینترنت می‌خواهد. آفلاین بودن APK به معنی آفلاین شدن چندنفره نیست.
- آدرس و کلید publishable موجود در HTML حفظ شده‌اند. کلید publishable برای قرار گرفتن در کلاینت طراحی شده، اما امنیت واقعی پروژه به تنظیمات دسترسی/قوانین سمت Supabase وابسته است؛ هرگز کلید service_role یا رمز محرمانه را داخل HTML یا APK قرار ندهید.
- این پروژه در این محیط به APK کامپایل نشده؛ برای خروجی APK باید آن را با Android Studio و Android SDK بسازید.
